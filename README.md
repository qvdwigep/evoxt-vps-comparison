## VPSを選ぶ前に押さえておくべき5つの基準

VPS おすすめ記事は世の中に溢れているが、比較軸がバラバラだと結局選べない。まずは判断の軸を5つに絞る。

1. **CPUの単核性能（クロック周波数）**：WebサービスやBot、APIサーバーなどは単核性能が効く。多くの格安VPSは2.2〜2.4GHz帯で頭打ちになる。
2. **ストレージの種類と容量**：NVMeかSSDか、5GBで足りるか60GB必要か。Dockerやデータベースを載せるなら20GBは欲しい。
3. **月間転送量とポート速度**：1Gbpsポートでも月500GBしか出ないプランと、月10TBまで出るプランでは使い勝手が別物。
4. **リージョンと回線品質**：日本から使うなら東京・大阪が第一候補。回線最適化の有無（CN2、9929、CMI等）が中国方面の遅延を大きく左右する。
5. **バックアップとセキュリティ**：週次バックアップが無料か有料か、ファイアウォールがコントロールパネルから設定できるか。

この5軸で測ると、**Evoxt** は「高い単核CPU性能＋無料週次バックアップ＋東京と大阪の二拠点＋暗号資産決済対応」という、海外格安VPSとしては珍しい組み合わせを提供していることが分かる。次章で実態を確認していこう。

## 海外VPSと国内VPS、VPS おすすめ はどっち？

国内VPS（Xserver VPS、ConoHa、さくらのVPS、WebARENA Indigoなど）は、日本語サポートと国内回線の安定感が強みだが、最小構成でも月額600円〜900円程度からスタートすることが多い。

一方、海外VPSは**ドル建ての格安価格帯**が最大の武器。**Evoxt** の場合、最小プラン VM-0.5 は月額2.99ドル（円換算で300円台後半）、それでいて1Gbpsポート、IPv4＋IPv6、無料週次オフサイトバックアップが付いてくる。国内事業者のエントリープランと比較しても遜色ないスペックを半値以下で提供している。

> ただし海外VPS全般に言える注意点がある。日本語サポートが基本ない（チケットは英語）、決済通貨がドル建てで為替変動の影響を受ける、海外事業者ゆえに日本の消費者保護制度が適用されにくい、あたりは事前に割り切っておきたい。

逆に言えば、「Linuxの学習」「Docker实验」「Bot/APIサーバー」「海外サイトのホスティング」「日本向けストリーミングアンロック」「ChatGPTのAPI経由利用」など、英語サポートに抵抗がなく自分で運用できる人には、海外VPSのコスパ優位性は大きい。

## 日本ユーザー向けの回線特性とストリーミングアンロック

Evoxt 東京リージョンは **Tier 1 ISP と BBIX、JPIX に接続** し、主要トランジットはソフトバンク系。日本国内からのアクセスは、ソフトバンク回線と相性が良い傾向がある。NTT系・KDDI系は国際トランジットを経由するため、ソフトバンク系と比較すると遅延が伸びるケースがある。

## お得に契約する方法：クーポンと長期割引

**VPS おすすめ** を探す読者にとって、料金は外せない要素。Evoxt をお得に使う方法を整理する。

- **長期前払い**：月払いだけでなく、最長3年契約まで選択可能。長期契約で割引が適用される。また、アカウントクレジットをチャージして未来の請求に充当することもできる。
- **公開クーポンの例**：コミュニティで確認されているコードとして、`AFF2261-btcvps`（VM-1以上で5%オフ）、`BHW595`（リカーリング割引）などがある。これらはコミュニティ投稿に基づくもので、いつ無効になるかは公式の告知待ち。
- **リソース単位の追加**：プランを大きく変えるより、CPU/RAM/IP/転送量を個別に追加する方が安く済むことが多い。これも実質的な割引手法。

> いずれのクーポンも、適用前にチェックアウト画面で割引が反映されているかを必ず確認すること。本記事執筆時点で有効性を保証するものではない。

## 登録からデプロイまでの流れ

手続き面で迷わないよう、登録からサーバー立ち上げまでの流れをまとめる。

1. **アカウント作成**：メールアドレスと氏名を入力。本人確認書類は通常不要。
2. **プラン選択**：リージョンとネットワークティア（Standard/Premium/Premium Plus）を選び、VM-0.5〜VM-16の中からプランを指定。
3. **OS選択**：Linux各種、Windows RDP（一部プラン）から選択。Debian、Ubuntu、AlmaLinux、Rocky Linux等の主要ディストロが揃う。
4. **決済**：クレジットカード、デビットカード、PayPal、Bitcoin、Litecoin、Ethereum、USDt Tron から選択。
5. **デプロイ**：支払い完了後、約2.5分以内に利用可能になる。コンソールからIPアドレスとrootパスワードを確認。
6. **運用**：コントロールパネルからモニタリング、ファイアウォール設定、VNC、クローン、バックアップ復元、サブアカウント権限付与 までブラウザ上で完結。
